# CDATE — prerequisites to verify

Covers **HT2022, HT2023, HT2024, HT2025, HT2026**.

**How to sign this off.** Every course below links to its page on kth.se, and every
judgement links the *exact kursplan* it was read from — the PDF KTH publishes in the
course's own version archive. Open the kursplan, read *Särskild behörighet*, and
confirm or correct. Nothing here needs the data files to be read.

A kursplan text is the unit of review, not a cohort: where several cohorts share the
same wording they are listed together on one item, and where a revision changed the
wording each version appears separately. Kursplan versions are per cohort because a
student is examined against the version in force when they sit the course.

Generated by `scripts/extract-from-kopps.mjs`. Prerequisites are the only field taken
from free text (*Särskild behörighet* on the course page), so every judgement below
needs a program coordinator to confirm or correct. Edit `src/data/cohorts/` (or the
curated `src/data/CDATE.json`) directly — this file is a worklist, not a source.
