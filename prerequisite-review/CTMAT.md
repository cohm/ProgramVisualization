# CTMAT — prerequisites to verify

Covers **HT2022, HT2023, HT2024, HT2025, HT2026**.

**How to sign this off.** Every course below links to its page on kth.se, and every
judgement links the *exact kursplan* it was read from — the PDF KTH publishes in the
course's own version archive. Open the kursplan, read *Särskild behörighet*, and
confirm or correct. Nothing here needs the data files to be read.

A kursplan text is the unit of review, not a cohort: where several cohorts share the
same wording they are listed together on one item, and where a revision changed the
wording each version appears separately. Kursplan versions are per cohort because a
student is examined against the version in force when they sit the course.

Generated by `scripts/extract-from-kopps.mjs`. Prerequisites are the only field taken
from free text (*Särskild behörighet* on the course page), so every judgement below
needs a program coordinator to confirm or correct. Edit `src/data/cohorts/` (or the
curated `src/data/CTMAT.json`) directly — this file is a worklist, not a source.

## The course's own prerequisite list looks out of date — report it (3)

These courses require a knowledge area that **this programme teaches**, but their list of qualifying courses does not include our course. CTMAT is the worked example: DD1385 and DD1380 ask for "programmering" while listing only `DD1310/DD1311/.../DD1331`, and CTMAT's own first-year programming course is DD1333. Neither syllabus has been revised since HT2021.

This is a defect in the **other course's** syllabus, not in this programme's data, so nothing was recorded automatically. Confirm the suggested course is really the intended prerequisite, add it here, and **report it to the coordinator or administrator of that course** so it is corrected at source — otherwise it stays wrong for every programme that uses the course. DD1328 needed exactly this and has since been fixed upstream: its VT2026 syllabus lists DD1333.
